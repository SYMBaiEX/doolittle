# Frontend quality contract

A passing build is operational evidence, not proof of good design. For a new
user-facing interface, Doolittle's managed coding delegation asks its existing
worker to establish and implement a coherent design direction before returning.
This is part of the shared cached worker prompt, not an additional model call,
model change, or prescribed visual theme. Existing brands, narrow changes and
explicit user preferences retain authority.

## Generation criteria

Before implementation, establish a compact brief: creative premise and audience,
composition/signature motif, semantic palette, typography hierarchy, imagery,
density and motion. Express those decisions in the actual interface. Generic
hero/card assembly, a stock component theme, or a palette change alone is not
evidence of a considered identity. Both restrained and expressive designs can
be appropriate; there is no universal ban on a color, font or layout.

Reuse existing brand documentation or the task report. Do not add design files
to an exact-file request, silently overwrite approved brand decisions, or ask
the user to choose every incidental detail. New interfaces should have
purposeful motion and interaction states, while honoring reduced-motion and
explicit no-animation preferences. Important content must remain visible
without animation.

## Review independently of build receipts

Inspect actual rendered desktop and narrow-screen output, primary interactions,
keyboard focus and button/text contrast. Text-only snapshots and capture cards
cannot establish these results. An unavailable renderer must be disclosed, not
replaced with a fabricated visual pass. Text contrast should be measured on
actual foreground/background values using the
[WCAG contrast criterion](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html),
not estimated from color names. Reduced-motion support is a product expectation;
[WCAG's interaction-animation guidance](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)
explains the underlying accessibility concern.

Keep the existing 110-point coding receipt grade unchanged. Record human visual
polish separately on a 1–5 scale, with concrete evidence for brand specificity,
composition/depth, typography/color coherence, motion/interaction craft and
responsive/accessibility quality. A 1 means unacceptable, 3 means usable but
generic or uneven, and 5 means exceptional and cohesive. Missing human review
is unavailable, never an inferred score. Unblinded feedback is valuable but is
not a blinded paired comparison. Critical readability or interaction failures
remain visible even when the operational grade passes.

Prompt tests prove that these criteria reach the selected worker once and that
original requirements are preserved. They do not prove improved taste. Evaluate
fresh samples using the same frozen task, route, fixture and fully isolated
state; show rendered artifacts and obtain human review before claiming quality
improvement. Do not manually repair generated benchmark apps between generation
and grading.
